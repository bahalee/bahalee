# Featured Projects

## RecruitFlow — Intelligent Recruitment Platform

**Java · Spring Boot · Angular · AI · Docker**

RecruitFlow is a next-generation recruitment platform designed to connect candidates with relevant opportunities using Artificial Intelligence.

The platform combines **Angular, Spring Boot, Hugging Face, MySQL, Redis, WebSockets and Docker** to provide an intelligent recruitment experience.

### Key Features

* AI-powered CV analysis and candidate matching
* Hugging Face integration
* Skill extraction using NER
* Candidate and recruiter dashboards
* CV management and analysis
* Real-time notifications with WebSockets
* JWT authentication
* Role-based access
* Progressive Web App
* Dark mode
* Redis caching
* Prometheus monitoring
* Grafana and Loki
* Docker and Docker Compose
* GitHub Actions CI/CD
* Nginx reverse proxy

### Architecture

### Technology Stack

**Frontend:** Angular 17+ · TypeScript · Tailwind CSS · Lucide Icons · PWA
